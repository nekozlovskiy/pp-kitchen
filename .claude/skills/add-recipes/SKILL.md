# Партия рецептов

Правила отбора — в `CLAUDE.md` (раздел «Правила по рецептам»). Перечитай их перед началом.
Рабочая папка для скачанного — scratchpad сессии (не репозиторий). Python по скачанным HTML запускать с `-I`.

## 1. Скачать статьи и рецепты

```bash
D=<scratchpad>/gs
bash .claude/skills/add-recipes/scripts/fetch.sh "$D" <url статьи> [<url> …]
```

Скрипт качает статьи по одной с паузой, вытаскивает ссылки `/recipe/ID` и докачивает рецепты (уже скачанные пропускает).

## 2. Разобрать

```bash
python3 -I .claude/skills/add-recipes/scripts/parse_gastronom.py "$D"
```

Печатает статьи (заголовок, автор, дата — для `sources.json`) и рецепты: автор, название, выход. Полные данные — в `$D/all.json` (состав с граммами и legacyName, шаги).

## 3. Отобрать

Оставить: автор `gastronom`, есть граммы, шаги не заглушки «Шаг 1», блюдо ПП, нет дубля на сайте (сверить название и состав с `src/data/recipes.json`). Ключи уже использованных статей — в `src/data/sources.json`. Что не взято и почему — сказать пользователю.

## 4. Записать партию

Составить `$D/batch.json` (формат — в начале `scripts/append_batch.py`): новые продукты с КБЖУ на 100 г, рецепты (шаги пересказаны), источники. Затем:

```bash
python3 .claude/skills/add-recipes/scripts/append_batch.py "$D/batch.json"
```

Скрипт проверяет уникальность id/названий/ключей и существование продуктов, дописывает три JSON и обновляет число рецептов в README и `index.html`.

Вручную после этого: новые продукты групп мясо/рыба/молочное/яйца/глютен → `src/lib/diet.ts`; крупы и мясо → `COOKED_FACTOR`; новые правила «штуки → граммы» → README.

## 5. Проверить

- `npm test` и `npm run typecheck` (формула КБЖУ, дубли, источники).
- Запустить агента `recipe-data-reviewer` на новые id.
- Показать пользователю список партии (название, ккал/Б на порцию, что не взято). **Пушить только после его одобрения** — затем `/ship`.
- Обновить заметку в памяти: какие статьи использованы, коммит, число рецептов.
