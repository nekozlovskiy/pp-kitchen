# Рецепты из рилсов

Общие правила данных — в `CLAUDE.md` и README («Откуда рецепты», правила «штуки → граммы»). Здесь — то, что отличает рилсы пользователя.
Рабочая папка — scratchpad сессии, не репозиторий.

## 1. Скачать подписи

Ссылки — файлом: в zsh `?` в адресе раскрывается как шаблон и команда падает.

```bash
D=<scratchpad>/reels; mkdir -p "$D"   # ссылки построчно в $D/links.txt
python3 -I .claude/skills/add-reels/scripts/fetch_reels.py "$D" @"$D/links.txt"
```

Скрипт убирает повторы и то, что уже на сайте; полная подпись, автор и дата — в `$D/captions.json`. Пометки в выводе:
- «нет состава» — рецепт не добавлять, попросить у пользователя состав (список кодов в конце отчёта);
- «состава мало» — прочитать самому: часто состав есть одной фразой.

## 2. Правила для рилсов (решения пользователя)

- Пользователь хочет **все** присланные рецепты, даже не ПП: сахар считаем сахаром (ст. л. 20 г), сливки и майонез берём. Отбросить рилс можно только спросив пользователя окном выбора.
- Нет шагов в подписи — короткие очевидные шаги + в `tip` «…по смыслу, подробности — в видео».
- Нет веса — штучное по README, остальное умеренной оценкой. **Каждая оценка и замена продукта** («сиртаки посчитан как фета», «пшеничные тортильи — как цельнозерновые») — в `tip`.
- **Диапазон — по середине** («250–300 г» → 275, «2–3 ст. л.» → 2,5), не по меньшему.
- **«По вкусу» — в `extras`**, даже если хочется оценить граммы. Масло «для жарки» без количества тоже не считаем.
- Английский — переводим: название, описание и шаги по-русски, в `tip` «Рецепт переведён с английского». Источник `title` — как у автора.
- Порция > 700 ккал — увеличить `servings` (`portionLabel` «½ …») и написать в `tip`.
- Подпись обрезана Instagram (кончается на полуслове) — дописать оставшиеся шаги по смыслу, отметить в `tip`.

## 3. Записать

`batch.json` в формате `add-recipes/scripts/append_batch.py`; у каждого рецепта `"video": "https://www.instagram.com/reel/КОД/"`. Источник: `site: "Instagram"`, `author: "@ник"`, `date` из `captions.json`, `title` — первая строка подписи. **Ключ `ig_…` сверить с `sources.json`** — короткие (`ig_salat_tunec`) уже бывают заняты.

```bash
python3 .claude/skills/add-recipes/scripts/append_batch.py "$D/batch.json"
```

Новые продукты: `diet.ts` (мясо/рыба/молочное/яйца/глютен; сыры — в `cheeseIds`), крупы и мясо — `COOKED_FACTOR`. Новые правила «штуки → граммы» — в README.

## 4. Проверить и отдать

`npm test`, `npm run typecheck`, агент `recipe-data-reviewer` (передать id и путь к `captions.json`). Показать пользователю итог, список «нет состава» и вопросы — окном выбора. Пушить после одобрения через `/ship`.
