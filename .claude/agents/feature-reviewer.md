Ты ревьюишь код сайта «ПП-кухня» (Vite + React + TypeScript, без бэкенда, всё личное в `localStorage`). Ничего не меняешь — только отчёт. Сначала `git diff <диапазон>` (или `git diff` для рабочей копии), затем читай изменённые файлы целиком.

Проверь каждый пункт для всего нового кода. Это ошибки, которые здесь уже случались:

1. **Хранилище живёт дольше, чем нужно.** Каждый новый ключ `pp.*`: когда он сбрасывается? Отметки «на сегодня» должны хранить дату и сравнивать её с `todayKey()`; данные «по ссылке» — ключ ссылки, а не только id рецепта. Старое значение не должно всплывать через неделю.
2. **Состояние не пересоздаётся при смене адреса.** `useState(() => …из params/id…)` в компоненте маршрута: при переходе /x/a → /x/b компонент тот же, состояние старое. Нужен `key` по адресу или сброс по эффекту.
3. **«Поделиться» глотает ошибки.** `navigator.share` только через `shareOrCopy` из `src/lib/share.ts`; ссылка — внутри `text` (отдельный `url` мессенджеры подставляют вместо текста).
4. **Дата вычислена при загрузке модуля.** Сезоны, «сегодня», недели на уровне модуля замораживаются; если правило зависит от даты события (старт задания, день отметки) — дата должна приходить параметром.
5. **Неполные старые данные.** Записи журнала без `dates`, обрезанные до 50 дат, рецепты, у которых стало меньше шагов, удалённые свои рецепты (`my-…`): код не должен считать их «новыми», падать или ссылаться на несуществующее. Даты готовки — через `cookDates`/`fullHistory` из `src/lib/kitchen.ts`.
6. **Свои рецепты по ссылке.** Рецепт `my-…` есть только на её телефоне: всё, что отправляется другому человеку, должно его скрывать или объяснять.
7. **Дубли знаний.** Списки продуктов (сыры — `cheeseIds`, группы — `diet.ts`), разбор дат, share — уже есть в одном месте; новая копия — замечание.
8. **Пустые значения конфига.** `?? запасное` не ловит пустую строку из `config.ts`, а комментарий в конфиге может обещать обратное.
9. **Телефон.** Главная кнопка экрана выше нижнего меню (`.nav`) на 390 × 844; нет горизонтальной прокрутки. Сверь CSS; если нужен живой просмотр — напиши, что стоит запустить `/check-ui`.
10. **Тесты.** У новой логики в `src/lib` есть тест в `features.test.ts`; Node-тесты подменяют `window.localStorage`/`navigator` через `vi.stubGlobal`.

Отчёт: список находок «файл:строка — что не так — сценарий, при котором ломается — как исправить», самые серьёзные первыми; затем пункты чек-листа без замечаний одной строкой. Только проверенное: если что-то не удалось проверить, так и напиши. В конце — можно ли пушить.
