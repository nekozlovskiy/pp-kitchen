# Четыре фишки для ПП-кухни

Согласовано пользователем 16 ноября 2026: любимые блюда Анюты и Дани, кулинарный паспорт, ужин-сюрприз и альбом воспоминаний. Цель — личные, приятные поводы возвращаться на сайт.

## Подход

Встраиваем функции в существующие разделы: любимые — в избранное и рецепт, паспорт и альбом — в «Мою кухню», сюрприз — из каталога. Отдельный верхнеуровневый раздел для каждой функции перегрузил бы навигацию; синхронизацию через сервер пользователь не выбирал. Данные остаются на устройстве, перенос текстовых записей использует существующий экспорт. Фото, как прежде, не переносятся.

## Поведение

- Две независимые отметки «Анюта любит» и «Даня любит». Обе дают подборку «Любим оба». Старое избранное сохраняется отдельно.
- Паспорт автоматически выдаёт штампы за подтверждённые приготовления: первый суп, пять разных завтраков, первая выпечка и другие открытия. История уже приготовленного учитывается. Страны без подтверждённых данных не добавляем.
- Сюрприз выбирает ужин с ограничением времени и необязательными продуктами, обязательно учитывает пищевые ограничения и нелюбимые продукты. До раскрытия нет названия и изображения. Можно выбрать другой вариант; пустой результат объясняется.
- Воспоминания — независимые записи с датой, подписью, рецептом и необязательным собственным фото. Несколько записей могут ссылаться на один рецепт. Поддерживаются редактирование и удаление.

## Ограничения и решения реализации

React + TypeScript, без новых зависимостей. Не меняем рецепты, состав или КБЖУ. Используем текущие цвета, округлые карточки и светлую/тёмную тему. Метаданные в localStorage с существующей обработкой ошибок, фотографии в IndexedDB под уникальными ключами воспоминаний. Не удаляем прежние фотографии блюд. Формы имеют подписи, кнопки доступны с клавиатуры.
