# ПП-кухня

Сайт-подарок для Анюты: журнал ПП-рецептов с КБЖУ. Vite + React + TypeScript, данные в JSON, без бэкенда.
Живой сайт: https://nekozlovskiy.github.io/pp-kitchen/ — деплой GitHub Actions при пуше в `main` (там же `npm test` и `npm run build`).

Команды: `npm run dev`, `npm test` (Vitest), `npm run typecheck`, `npm run build`.

## Данные

- `src/data/recipes.json`, `ingredients.json` (КБЖУ на 100 г), `sources.json` (откуда взят рецепт). Схема — `src/types.ts`.
- Как добавить рецепт и правила «ложки/штуки → граммы» — в README, разделы «Как добавить рецепт» и «Откуда рецепты».
- `src/lib/nutrition.test.ts` проверяет целостность: формула 4·Б+9·Ж+4·У (±8%) для каждого продукта, дубли рецептов, ссылки на источники. Он должен быть зелёным после любой правки данных.

## Правила по рецептам (решения пользователя)

- **Только проверенные источники со ссылкой.** Рецепты «по мотивам», придуманные самостоятельно, запрещены. Каждый рецепт ссылается на ключ в `sources.json`; автора и дату статьи брать из её JSON-LD Article, не придумывать.
- Состав и граммы — как в источнике; шаги пересказывать своими словами; КБЖУ считается по таблице продуктов (не копировать с сайта).
- Gastronom.ru: брать только рецепты автора «gastronom» (редакция), не «Мой Магнит» и не пользовательские. Граммы — массив `ingredients` (quantityInGramms + legacyName); если они противоречат тексту или шагам — брать по тексту и пояснить в `tip`. Качать по одному с паузой (параллельно — HTTP 503).
- eda.ru (теперь eda.rambler.ru), edimdoma, povarenok, russianfood, 1000.menu — пользовательские, не брать. Исключение — рецепт, который пользователь прислал ссылкой сам: его брать, штуки и ложки переводить в граммы по README.
- Подборки «лучших рецептов» без пометки ПП (Леди Mail.ru и т. п.) — не брать без явного согласия пользователя. Соусы не берём.
- Не ПП (сахар, маскарпоне, майонез, много сливочного масла) и тривиальное пропускать. Порцию > 700 ккал делить, указав в `tip`.
- Сахар: «сахар или сахарозаменитель» → сахарозаменитель (`erythritol`); только сахар → сахар.
- Без веса у стандартного штучного продукта (лепёшка 40 г, лаваш 80 г) рецепт не пропускать — брать вес из README.
- Новый продукт из групп мясо/рыба/молочное/яйца/глютен — дописать в `src/lib/diet.ts`; новая крупа или мясо — коэффициент в `COOKED_FACTOR` (`src/lib/nutrition.ts`).
- После партии — обновить число рецептов в README и в `description`/`og:description` в `index.html`.
- Не менять КБЖУ или состав существующих рецептов и не добавлять новые функции сайта без согласия пользователя. Дисклеймер о КБЖУ оставлять, медицинских советов не давать.
- Каждую партию пользователь одобряет перед пушем.

## Автоматизация

- `/add-recipes` — партия рецептов (скрипты в `.claude/skills/add-recipes/scripts`).
- `/add-reels` — рецепты из рилсов, присланных пользователем: подписи без логина, правила оценок и перевода.
- `/check-ui` — проверка экрана на ширине телефона в собранном сайте (сброс service worker, снимки, тёмная тема).
- `/ship` — тесты, сборка, пуш, проверка деплоя.
- Агент `recipe-data-reviewer` — сверка новой партии с исходными страницами перед пушем.
- Хук в `.claude/settings.json` запускает тесты данных после правки `src/data/*.json`.
