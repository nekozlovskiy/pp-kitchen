# ПП-кухня

Журнал ПП-рецептов для Анюты: 548 блюд, у каждого калории, белки, жиры и углеводы на порцию. Vite + React + TypeScript, данные в JSON, без бэкенда.

## Запуск

```bash
npm install
npm run dev      # локально на http://localhost:5173
npm test         # тесты расчёта КБЖУ и поиска
npm run build    # сборка в dist/
```

Сайт публикуется на GitHub Pages автоматически при пуше в `main` (`.github/workflows/deploy.yml`). В настройках репозитория: Settings → Pages → Source: GitHub Actions.

## Как добавить рецепт

1. Проверьте, что все продукты есть в `src/data/ingredients.json`. Если продукта нет, добавьте его с КБЖУ на 100 г **сырого** веса:

   ```json
   { "id": "pear", "name": "Груша", "per100": { "kcal": 47, "p": 0.4, "f": 0.3, "c": 10.3 } }
   ```

   Необязательные поля: `"unit": "ml"` для жидкостей, `"piece": { "grams": 55, "label": "шт" }` для штучных продуктов.

2. Добавьте рецепт в конец `src/data/recipes.json`:

   ```json
   {
     "id": "pear-oats",
     "category": "breakfast",
     "title": "Овсянка с грушей",
     "description": "Одна-две фразы о блюде.",
     "timeMinutes": 10,
     "level": "Легко",
     "servings": 1,
     "art": "bowl",
     "source": "ovsyanka",
     "ingredients": [
       { "id": "oats", "grams": 50 },
       { "id": "pear", "grams": 120 }
     ],
     "extras": [{ "name": "Корица", "amount": "щепотка" }],
     "steps": ["Первый шаг.", "Второй шаг."],
     "tip": "Совет (необязательно)."
   }
   ```

   - `category`: `breakfast`, `lunch`, `dinner`, `snack`, `dessert`.
   - `level`: `Легко`, `Средне`, `Сложно`.
   - `art`: иллюстрация: `plate`, `bowl`, `soup`, `glass`, `jar`, `pan`, `cake`, `cookies`, `roll`, `toast`, `pancakes`, `fish`, `salad`, `cutlets`, `muffin`, `pie`, `cakeslice`, `balls`, `eggs`, `spirals`, `pot`, `casserole`, `bread`, `mousse`.
   - Необязательные поля: `timeNote` (например `"+ ночь в холодильнике"`), `portionLabel` (`"2 котлеты"`), `image` (путь к фото в `public/img`), `video` (ссылка на пост в Instagram вида `https://www.instagram.com/reel/КОД/` без меток после `?`: на странице рецепта появится кнопка «Смотреть видео» с официальным плеером Instagram).
   - `source`: ключ из `src/data/sources.json`. Если рецепт из новой статьи, сначала добавьте её туда (сайт, название, автор, дата, ссылка).
   - Соль, специи и всё «по вкусу» пишите в `extras`: они не участвуют в расчёте.

## Откуда рецепты и как считается КБЖУ

Рецепты взяты из редакционных подборок «лучших ПП-рецептов» Леди Mail.ru, из ПП-подборок журнала Food.ru (только рецепты штатных кулинарных редакторов: у них тип автора `vip` и подпись «кулинарный редактор Food.ru»; рецепты читателей не берём), из ПП-подборок журнала «Гастроном» (gastronom.ru, только рецепты с автором `gastronom`; граммы берём из поля `quantityInGramms` в данных страницы, без партнёрских рецептов «Мой Магнит») и из рилсов в Instagram, отобранных вручную; ссылка на источник есть у каждого рецепта. Подпись к рилсу без входа в аккаунт можно прочитать на странице `https://www.instagram.com/reel/КОД/embed/captioned/`. Посты, где в подписи нет граммовок, не добавляем. Состав и граммовки — как в источнике, шаги пересказаны своими словами. Цифры КБЖУ с сайтов не используются: всё считается по таблице продуктов.

Правила перевода в граммы:

- диапазон («2–3 ст. л.») берётся по середине;
- если в источнике «А или Б», берётся первый вариант; исключение — «сахар или сахарозаменитель» (в любом порядке): считаем сахарозаменитель (эритрит, 0 ккал); где указан только сахар — считаем сахар;
- «по вкусу», «по желанию» и масло «для жарки» без количества в расчёт не входят;
- ложки: масло ст. л. 17 г, ч. л. 5 г; мёд ст. л. 30 г, ч. л. 10 г; йогурт и сметана ст. л. 25 г; мука и хлопья ст. л. 10 г; чиа ст. л. 12 г;
- штуки: яйцо 55 г, белок 33 г, желток 18 г, банан 120 г, яблоко 150 г, морковь и луковица 80 г, помидор 120 г, черри 15 г, огурец 120 г, авокадо 140 г мякоти, куриное филе 200 г, кабачок 200 г, баклажан 300 г, корнишон 15 г, солёный огурец 60 г, шляпка шампиньона 20 г, креветка 10 г, перепелиное яйцо 11 г, лист салата 10 г, пучок салата 100 г, лаваш 80 г, лепёшка или тортилья 40 г, лист рисовой бумаги 9 г, ½ граната 100 г зёрен, горсть шпината 30 г, пучок зелёного лука 50 г, ⅓ стакана булгура 60 г; тахини ст. л. с горкой 20 г; картофелина 100 г, редиска 20 г, оливка 4 г, мякоть манго 200 г, ст. л. отрубей с верхом 10 г; киви 75 г, перец 150 г, небольшой кочан салата 300 г; ст. л. с горкой риса 25 г, кефира 15 г, консервированной фасоли 20 г, томатной пасты 20 г, соевого соуса 15 г, какао и кокосовой стружки 10 г; сиропы (топинамбур, агава) как мёд.

Число порций и время в источниках обычно не указаны: их определили мы по выходу блюда и шагам.

3. Запустите `npm test`. Тесты проверят, что все продукты существуют, id уникальны и калорийность порции разумна.

На странице рецепта есть и КБЖУ на 100 г готового блюда. Вес готового блюда оценивается в `src/lib/nutrition.ts` (`dishWeight`): крупы, макароны и бобовые получают привар (гречка ×2,5, рис ×2,8 и т. д.), мясо и рыба — ужарку (×0,65–0,8), в супах к весу прибавляется вода и бульон из «по вкусу». Это оценка, поэтому на сайте стоит знак «≈».

КБЖУ нигде не хранится готовыми числами: оно считается из граммов продуктов, поэтому правка граммов сама меняет итог.

## Где что лежит

- `src/config.ts`: имя, посвящение на обложке, цель по калориям по умолчанию, текст пометки о КБЖУ.
- `src/lib/nutrition.ts`: расчёт КБЖУ, порции, доли калорий.
- `src/lib/search.ts`: поиск по основе слова («курица» находит «куриная грудка»).
- `src/art/Art.tsx`: SVG-иллюстрации блюд.
- `src/styles/tokens.css`: цвета и шрифты для светлой и тёмной темы.
- `src/lib/diet.ts`: какие продукты попадают под «Без мяса», «Без рыбы», «Без молочного», «Без яиц», «Без глютена». Новый продукт из этих групп нужно дописать сюда.
- `src/lib/steptime.ts`: поиск времени в шагах («25–30 минут», «полчаса») для кнопок-таймеров.
- `src/lib/pantry.ts`, `src/lib/menu.ts`: «Из того, что есть» и подбор меню на день.
- `src/styles/kitchen.css`: стили таймеров, пошагового режима, отметок, меню.

## Личные данные

Бэкенда нет: избранное, «Мой день», покупки, таймеры, оценки, заметки, «готовила», продукты дома и ограничения в еде хранятся в `localStorage` браузера (ключи `pp.*`), свои фото блюд — в IndexedDB (`pp-photos`). Они живут только на том телефоне, где их сделали, и пропадут, если очистить данные сайта в браузере.
