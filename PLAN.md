# План: сайт «ПП-кухня» (рецепты с КБЖУ)

Ты Claude Code. Прочитай этот файл целиком, затем открой `reference/pp-kitchen.html`: это рабочий прототип в одном файле. В нём уже есть дизайн, 16 рецептов и таблица продуктов с КБЖУ. Нужно превратить его в нормальный проект и довести до продакшена. Работай этапами из раздела 7, после каждого этапа коротко сообщай, что сделано, и жди моего ответа, если есть вопрос.

## 1. Цель

Подарок для любимой девушки: красивый, уютный сайт с ПП-рецептами. У каждого рецепта калории, белки, жиры и углеводы на порцию. Открывать его будут в основном с телефона, на кухне, часто одной рукой. Весь интерфейс на русском.

Главное: быстро найти рецепт, понять, сколько в нём калорий, и приготовить.

## 2. Стек

- Vite + React + TypeScript.
- Обычный CSS с переменными (design tokens), без тяжёлых UI-библиотек.
- React Router для страниц (в режиме `HashRouter`, чтобы работало на любом статическом хостинге).
- Данные в JSON-файлах, без бэкенда.
- Vitest для тестов расчёта КБЖУ.
- Деплой: GitHub Pages или Netlify (спроси меня, что удобнее).

## 4. Модель данных

Калории и БЖУ нигде не хранятся готовыми числами. Они считаются из продуктов, чтобы правка граммов сама меняла итог.

```ts
type Ingredient = {
  id: string;            // "chicken"
  name: string;          // "Куриная грудка (сырая)"
  per100: { kcal: number; p: number; f: number; c: number };
  unit?: "g" | "ml";     // по умолчанию граммы
  piece?: { grams: number; label: string }; // 1 яйцо = 55 г, "шт"
};

type Recipe = {
  id: string;
  category: "breakfast" | "lunch" | "dinner" | "snack" | "dessert";
  title: string;
  description: string;
  timeMinutes: number;
  timeNote?: string;     // "+ ночь в холодильнике"
  level: "Легко" | "Средне" | "Сложно";
  servings: number;
  portionLabel?: string; // "2 котлеты"
  ingredients: { id: string; grams: number }[];
  extras?: { name: string; amount: string }[]; // соль, специи, "по вкусу"
  steps: string[];
  tip?: string;
  image?: string;        // путь в public/img
};
```

Перенеси таблицу продуктов и 16 рецептов из прототипа в JSON без изменения цифр. В прототипе значения уже проверены: расчёт совпадает с формулой 4·Б + 9·Ж + 4·У с точностью до нескольких процентов.

## 5. Функции

**Этап MVP**
1. Главная: герой-блок, «Рецепт дня» (меняется каждый день), поиск, категории, быстрые фильтры («Белка от 20 г», «До 20 минут», «Избранное»), ползунок максимальной калорийности, сортировка.
2. Поиск понимает русские формы слов: «курица» находит «куриная грудка». В прототипе есть простая основа слова, её можно улучшить.
3. Карточка рецепта: категория, время, калории крупно, мини-кольцо КБЖУ, граммы Б/Ж/У, кнопка «в избранное».
4. Страница рецепта с собственным адресом, чтобы можно было отправить ссылку на конкретное блюдо. Кольцо КБЖУ, проценты калорий, пересчёт продуктов под нужное число порций, чекбоксы у продуктов, шаги, совет.
5. «Мой день»: добавление порций, сумма КБЖУ, цель по калориям, остаток. Хранится в localStorage.
6. Избранное в localStorage.
7. Светлая и тёмная тема по системным настройкам.

**После MVP**
8. Список покупок: выбрать несколько рецептов, получить сводный список продуктов с суммой граммов по каждому. Копирование в буфер обмена.
9. PWA: манифест и service worker, чтобы сайт можно было поставить на экран телефона и открывать без интернета.
10. Печать рецепта: отдельные стили `@media print`.

## 6. Дизайн

Основа: дизайн из прототипа. Не заменяй его «типовым» светлым шаблоном и не добавляй эмодзи как маркеры разделов.

- Шрифты: Unbounded (заголовки и крупные числа, умеренно) и Onest (текст). Оба поддерживают кириллицу, подключи через Google Fonts с запасными системными шрифтами.
- Цвета (токены): фон светло-зелёный, поверхности белые, акцент малиновый для кнопок и сердечка. Белки синие, жиры янтарные, углеводы зелёные. Точные значения для светлой и тёмной темы возьми из `:root` в прототипе.
- Крупные числа калорий в Unbounded: это главный визуальный акцент. Всё остальное спокойное.
- Кольцо КБЖУ рисуется SVG с долями по калориям, а не по граммам.
- Мобильная версия первична: проверять на ширине 360 px. Минимальный размер зоны нажатия 44 px. Рецепт на телефоне открывается как нижний лист, на компьютере как центральное окно.
- Уважать `prefers-reduced-motion`, видимый фокус для клавиатуры, контраст не ниже AA.

## 7. Этапы

1. **Каркас.** Vite + React + TS, токены, шрифты, структура папок, перенос данных в JSON. *Готово, когда:* проект запускается, данные импортируются, типы проходят проверку.
2. **Расчёт.** `nutrition.ts` и тесты: сумма по продуктам, деление на порции, проценты, округление. *Готово, когда:* тесты зелёные, результат для каждого из 16 рецептов совпадает с прототипом (допуск 1 ккал).
3. **Каталог.** Главная, карточки, поиск, фильтры, сортировка, избранное. *Готово, когда:* всё работает на 360 px и на 1280 px.
4. **Страница рецепта.** Маршруты, порции, чекбоксы, кнопки «в избранное» и «в мой день».
5. **Мой день.** Сумма КБЖУ, цель, остаток, очистка.
6. **Полировка.** Тёмная тема, доступность, пустые состояния, 404, мета-теги и превью для ссылок.
7. **Деплой.** Сборка, публикация, проверка на реальном телефоне. Короткая инструкция в README, как добавить новый рецепт.
8. **После MVP:** список покупок, PWA, печать (по моей команде).

## 8. Проверки перед сдачей этапа

- `npm run build` без ошибок и предупреждений TypeScript.
- Тесты проходят.
- Нет горизонтальной прокрутки на 360 px.
- Lighthouse на мобильном: Performance, Accessibility и Best Practices не ниже 90.
- Все данные из localStorage оборачиваются в try/catch: сайт должен работать и без них.
